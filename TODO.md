# GONE — Project outcomes

## Previously delivered
- [x] **Clean, empty personal tracker:** New users start with no seeded/sample transactions; users can add and remove money-in and money-out entries, set or remove a savings goal, and see current-month received/spent totals and goal progress.
- [x] **Local-only data boundary:** Persist information in the same browser profile; no Manus Server, managed MySQL, real account authentication, or cross-device sync. Warn that anyone with access to that browser profile may see its entries.
- [x] **Warm-earth palette and static deployment:** Keep the approved deep-espresso, camel, terracotta, dusty-rose, and muted-olive colors; retain dependency-light GitHub/Vercel static hosting.

## Completed current request
- [x] **Welcome and onboarding:** First-time visitors see the GONE welcome screen with “Know where it went.” and a “Get started” path. Optional setup stores the local display name, monthly budget, and selected daily reminders; “Start with an empty ledger” skips setup. Setup completion stays in this browser. There is no password sign-up/login or claim of a secure account.
- [x] **Working navigation:** Routes work between Home, Add, Entries, Insights, Savings, and Split; navigation displays the active route, supports browser back/forward and static-host refreshes, and keeps one add action available throughout the app screens. On route changes, keyboard focus moves to the main screen and an accessible live region announces its title.
- [x] **Functional daily reminders:** Optional Chai ₹20, Metro ₹50, and Recharge ₹99 templates are not transaction history until used. Toggling one on creates one dated spending entry; toggling it off removes that reminder-generated entry; “Skip all today” skips unmarked reminders. Unmarked reminders auto-log at midnight while the page is open, or on return for the immediately previous day if the page was closed; auto-logged entries are labeled.
- [x] **App screens and forms:** Home shows a neutral time-based greeting, budget-left progress, spent-today/spent-this-week/biggest-expense summaries, daily reminders, and recent entries. Home “See all” opens Entries filtered to the last 7 days. Add supports spending (`title`, `amount`, `category`, `date`) and received money (`source`, `amount`, `date`); `5000` formats as `5,000`. Entries can be filtered by category and date range. Insights shows category, seven-day, and monthly summaries in CSS chart areas with `chart-category`, `chart-trend`, and `chart-monthly` mount IDs. Savings supports `target_amount`, recurring `monthly_income`, `bonus_amount`/`bonus_source`, and goal progress; its savings chart exposes `chart-savings-trend`, “View expenses” opens the last 7 days, and “Adjust goal” focuses the goal form. Split accepts `total_amount`, comma-separated `friends`, and `description`, calculates equal shares, and stores the result locally.
- [x] **Distinctive typography:** Self-host the clean Manrope variable font with its SIL Open Font License and use it throughout while preserving the approved warm-earth palette.
- [x] **Preserve local data:** Migrate existing local ledger entries and savings goal to the expanded browser schema; first-time users still begin with no sample transactions. Keep all app data in this browser profile without a server, real login, or cross-device sync.
